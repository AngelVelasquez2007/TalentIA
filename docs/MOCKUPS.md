# Mockups / wireframes de las pantallas implementadas

## Login
```text
+-----------------------------+
| TalentIA                    |
| Correo [________________]   |
| Clave  [________________]   |
| [ Ingresar ]                |
| ¿No tienes cuenta? Registro |
+-----------------------------+
```
## Registro
```text
+-----------------------------+
| Crear cuenta candidato      |
| Nombre / Apellido           |
| Email / Contraseña          |
| [ Crear cuenta ]            |
+-----------------------------+
```
## Listado de vacantes / dashboard
```text
+-------------------------------------------------------+
| TalentIA    Vacantes    Postulaciones    Ingresar/Salir |
+-------------------------------------------------------+
| Encuentra tu siguiente oportunidad     [N vacantes]   |
| [ Buscar por título, ubicación... ]                    |
| +------------------+  +-----------------------------+ |
| | Título, requisitos|  | Título, requisitos          | |
| | salario, modalidad|  | salario, modalidad         | |
| | [Evaluar perfil] |  | [Evaluar perfil]          | |
| +------------------+  +-----------------------------+ |
| [Publicar vacante] visible a reclutador/admin          |
+-------------------------------------------------------+
```
## Formulario de vacante (reclutador/admin)
```text
| Título        | Empresa      |
| Descripción (texto largo)   |
| Requisitos (texto largo)    |
| Salario min   | Salario max  |
| Modalidad     | Ubicación    |
| [Publicar vacante]          |
```
## Detalle contextual de compatibilidad
```text
| Vacante: Desarrollador Angular |
| Mi perfil [_______________]    |
| [Calcular] [Postularme]        |
| 75% / coincidencias / faltantes|
```
## Postulaciones
```text
| Vacante | Estado | Puntuación |
| Angular | revisión | 75%      |
| Reclutador: cambiar estado    |
```
Los wireframes reflejan las vistas implementadas; se pueden reproducir como capturas del navegador para la entrega.
